# 📖 Overview

Retail360 is a modern retail management platform developed to help businesses digitalize and optimize their retail operations. The system was designed to solve common retail business challenges such as inventory tracking, stock management, reporting, user management, and operational monitoring.

The platform provides a centralized dashboard for managing retail activities efficiently through a responsive and user-friendly interface.

Retail360 was developed as part of an ICT Project Management and System Development project using modern frontend technologies and best development practices.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yenadh/retail-360.git
```

---

## 2️⃣ Navigate to the Project Folder

```bash
cd retail360
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Run Development Server

```bash
npm run dev
```

---

## 5️⃣ Open the Application

```bash
http://localhost:3000
```

---

# 🚀 Production Build

## Build Application

```bash
npm run build
```

## Start Production Server

```bash
npm start
```
